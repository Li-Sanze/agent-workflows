# 既有显示集成的维护

在受控更新会影响已安装的 HUD／statusline 适配器时阅读。本页补充主 Skill 的集成验收，不扩展为新集成安装、日常 UI 编辑或后台监控；用户另行授权的修复按其范围执行。

## 先关联源码、入口与证据

从当前显示配置解析实际入口，再核对本机安装清单；文件名相同或旧探针能运行，都不能代替当前调用关系。已有清单字段可复用，不要求迁移为统一格式。

| 对象 | 本机需要保留的关联 |
| --- | --- |
| 用户入口与恢复对象 | 当前显示命令、启停字段、配置原值及字段是否原本存在；仅列本轮相关字段 |
| 适配器源码 | 实际文件集、来源或本地源码位置、内容版本或文件摘要，以及对应离线自检入口；不要只保存显示截图 |
| 原生载荷与协议 | 观察到的原生版本、载荷身份或摘要、输入来源与字段约定；版本是观察锚点，不是未来固定目标 |
| 采集链路 | 原采集入口、启停与调用关系、账号和额度池的对应证据、既有网络策略的注入位置；不保存凭据 |
| 用户显示偏好 | 模型名与思考强度来源、额度窗口与已用／剩余口径、主题、宽度及叠加／替换模式 |

实际入口和原生版本应与这组源码可对照；缺少源码来源或版本绑定时明确缺口，不凭一份旧清单自动覆盖运行文件。维护 Skill 不自动分发或替换渲染器；源码迁移、修复或重新部署须符合本轮授权。

本机路径、摘要、代理地址／端口、账号线索、当前模型与读数留在本机，不复制进公共 Skill。将临时探针与诊断回执明确标为历史、不可用作激活或恢复入口；不要执行清单中的旧探针命令。历史测试结论标明对应版本和场景，不能冒充本次验证。

## 按原生语义比较

- 只按当前原生契约归一默认值。例如某实现省略 `stack_with_default: false` 可与显式 `false` 等价，`true` 仍是实际差异；不能把所有缺失字段都视为相同。比较 JSON 摘要时保留一致的序列化约定，避免将格式差异判为用户配置变化。
- 分开保留叠加／替换模式与键盘行为证据。替换默认栏可能一并隐藏模型和快捷键提示；显示消失不能推断快捷键失效或已验证。用户当前模式是保护项，不作为其他环境的默认。
- 模型名与思考强度来自当前原生数据；缺失时如实处理，不硬编码产品简称、历史模型或强度。用户后来换模型或修改同一配置时，不用安装快照覆盖。
- 明确额度的来源、窗口和方向：已是剩余比例的字段不再取反；已用百分比只在契约确认后换算。区分精确零、满额、接近边界、缺失、禁用和过期；多个模型池或账号不互相代替。用户指定的额度池可不同于当前模型，显示须明确标识。
- 绝对重置时间与相对倒计时按原生契约处理。缺少上游采集时间时，不以本地接收时间或旧快照宣称实时；缺失或过期按该集成约定显示未知，不补查额度。

## 复用离线自检与被动观察

先检查已有自检入口的实际行为，再执行其适用部分；名为 doctor、help 或 version 不代表没有更新或联网副作用。不为这项验收启动 AI CLI、新建采集进程、触发刷新／额度命令或发送模型提示词，也不安装自检依赖。

优先复用现有合成样例与语义测试，核对额度方向、窗口隔离、边界、过期、完整模型与强度，以及实际启用布局的常用宽度；未覆盖的极窄宽或键盘交互如实列出。样例只送到隔离的显示进程，不注入真实采集端，不回写用户设置、基线、日志或输入缓存；禁用运行时字节码等无关落盘。

显示进程保持其既有禁网隔离。沙箱能力的被动查询只能证明相应限制，不能代替原生采集或请求路径的证据；不额外发送出网／本地请求来证明拒绝。不能应用所需隔离时安全降级，不脱离沙箱重试，也不自动放宽权限。

部分平台或父沙箱会阻止再次应用沙箱；例如内层可能返回 `exit 71`，外层包装器捕获后输出未知并返回 `0`。这是安全降级，不是渲染、禁网能力和原生数据均已验收通过。分开记录内层失败、外层回执与可见输出，避免把“没有刷错”判为正常。

对已有会话只做被动观察：分别核对原生采集仍工作、适配器实际显示和所需网络证据。显示脚本不请求，不代表原生采集无需代理；代理配置相同也不代表请求已经走该路径。必要连接证据关联现有目标进程和实际连接；无连接可观测时标为未验证，不强制制造请求。不得改用其他工具、账号或凭据补齐读数。

## 判定与恢复

| 观察结果 | 判定与动作 |
| --- | --- |
| 只因版本、托管 helper 或摘要变化，尚未发现行为失效 | 待复核；审查实际契约和证据，不刷新清单凑通过 |
| 内层失败后安静输出未知，外层成功退出 | 安全降级；不能算完整通过，继续说明原因与未验证项 |
| 样例通过，但原生采集、实际显示或必需路径证据不足 | 分项报告已验证与未验证，不能将必需项降为可选 |
| 原采集、显示或必需隔离实际失效 | 按本轮变更范围处理；不回灌旧托管 helper、不整份还原配置、不直连或切账号绕过 |

恢复前重读当前用户字段，只恢复本轮替换且未被用户后来修改的对象，保留原字段的缺省状态。完成有依据的修复与验收后才更新本机清单，并保留此前观察的版本范围；不把用户新选择误写成安装损坏，也不把历史成功升级为未知版本兼容承诺。
